# CIR Data Engineering Pipeline

##  Overview

This project presents the data engineering work carried out during
my internship at the French Ministry of Higher Education and Research
in 2024.

The project focused on the processing, transformation and analysis
of data related to the **Crédit d'Impôt Recherche (CIR)**.

The objective was to build reproducible data-processing workflows
for managing and analyzing structured and semi-structured datasets.

> ⚠️ For confidentiality reasons, original institutional data are
> not included in this repository.

---

##  Objectives

The main objectives of the project were:

- Data collection and preparation
- Data cleaning and transformation
- Management of structured and semi-structured data
- Database manipulation
- Statistical processing of CIR data
- Development of reproducible data workflows
